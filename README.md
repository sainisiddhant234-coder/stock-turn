# Stock Turn Calculator

A clean, free **Inventory Turnover (Stock Turn)** calculator website.

## Features
- Instant Stock Turn calculation
- Days Inventory Outstanding
- Average Inventory
- Simple interpretation of results
- Fully responsive dark theme
- Pure HTML + CSS + JavaScript (no frameworks)

## Live Demo
After enabling GitHub Pages, your site will be available at:
`https://sainisiddhant234-coder.github.io/stock-turn/`

## How to use the calculator
1. Enter **Cost of Goods Sold (COGS)**
2. Enter **Beginning Inventory** and **Ending Inventory**
3. Choose the period (Year / Quarter / Month / Custom)
4. Click **Calculate Stock Turn**

## Formula
```
Stock Turn = COGS ÷ Average Inventory
Average Inventory = (Beginning + Ending) ÷ 2
Days Inventory Outstanding = Period days ÷ Stock Turn
```

## Deploy on GitHub Pages
1. Go to your repository → **Settings**
2. In the left sidebar click **Pages**
3. Under **Source**, select **Deploy from a branch**
4. Branch: `main` → folder: `/ (root)`
5. Click **Save**

Your site will be live in about 1–2 minutes at:
https://sainisiddhant234-coder.github.io/stock-turn/
